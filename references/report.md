# 自包含报告

读者首先需要明确结论和依据。默认中文、简洁回答，通常约500—900字作为编辑目标，复杂问题可适度增加以保留决定性证据，不机械限字。优先3—5段或少量要点，不铺满诊断系统的章节和表格。完整研究深度放附件，主报告只留会改变判断的内容。

推荐阅读顺序：**我的判断 → 为什么更支持它（2—3项决定性证据及最强反证）→ 接下来怎么看 → 什么会让我改判。** 这是表达顺序，不是要求重复四遍结论。

## 必须回答的内容

以下内容应在短正文中自然覆盖，不要求分别设章节；完整假设表、时间线和计算过程放研究附件。

1. **现象核实与结论**：问题前提成立到什么范围；最有证据的解释是什么，哪里仍未决。用紧凑的一句话交代对象、观察窗口、信息截止日和前瞻期限。
2. **决定性证据**：变化幅度、时点、对照、具体暴露及来源。关键数字带日期、口径与定位，读者不用打开附件才能理解。
3. **为什么更支持这个解释**：用能理解的业务/收益机制串起事实→变化→暴露→结果；指出它比最强替代解释多解释了什么，引用实际验证结果。正文讲最关键的比较，完整假设表放附件。描述算术贡献、机制推断与残差的边界。
4. **接下来怎么看**：主判断与依据、历史驱动是否延续、市场已反映多少的证据边界、最重要的替代情景和证伪条件。若不选主方向明确原因。
5. **前次判断复盘**：有历史版本才写；简述兑现、推翻或仍待检验的判断，分别评价结果和机制。
6. **限制与后续观察**：什么缺口可能改变结论、已尝试哪些路径、下一项最有区分力的证据何时可看。末尾链接调查档案。

“主因：情绪；建议关注政策”不满足交付。长表和资料堆积也不能替代主次判断。篇幅由决定性证据决定，不能靠重复摘要、根因和结论扩充。

## 证据与置信度

事实、来源自身解释和本次推断分别写清。高质量来源中的观点仍需检验；关键推断引用支持它的具体事实，不能只在文末放一串网址。

现象、历史解释、未来推断分别给出有依据的完成程度。可使用“已核实/部分核实”“较强支持/部分解释/未决”“有条件主判断/暂不选方向”。不把它们压成一个整体已解决的标签。

置信度可以用高/中/低或文字说明，分别解释事实质量、因果识别与未来不确定性。没有校准模型时不用小数分值或涨跌概率装饰报告。

数量分析写公式、输入、日期、权重、交互或残差；代理估算标明口径和误差来源。对照检验写实际结果和识别限制；没执行的方案不能写成验证结果。

## 默认范围

默认给历史解释与未来判断、观察指标，不要求个人买入日期/持仓金额，也不默认推荐买卖或换仓。若用户明确要求投资决策，再补齐影响决策的个人约束；研究结论与个人决策依据分开。

若现象不成立或无法核实，纠正前提并说明剩余可研究的问题；不为了填未来章节编方向。用户明确只要历史时，也不强制预测。

## 交付

按 [记录与复盘](review.md) 保存短主报告、详细研究附件和冻结的前瞻记录。用户直接调用时，将已保存 `report.md` 的完整正文作为最终回复，末尾附详细研究链接；不能仅给完成通知或路径，也不能把详细附件全部打印。机器调用按约定返回数据。

报告可以简练，但必须独立可读、结论有主次、边界清楚。未取得的数据、尚未执行的检查及尚未到期的预测不能宣称完成验证。
