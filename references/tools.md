# 来源与工具：围绕要验证的解释取证

技能提供研究工作流，不自带数据订阅、统一取证CLI或实时行情。使用当前可用工具，先检查与本次问题有关的接口、权限和真实返回，不把安装成功当取证成功。

行情、政策、费率、持仓和事件等时效性事实需要实际检索。优先原始材料，结构化数据便于计算，外部分析便于发现解释；三者各司其职。已有授权范围内的公开备用来源、本地缓存和计算可以自主推进。

## 按证据需要选入口

| 需要 | 首选材料 | 核对事项 |
|---|---|---|
| 股票/行业价格与成分 | 交易所、指数发布方、已授权数据商 | 复权、日期、成分与权重时点、总回报或价格回报 |
| 公司经营与事件 | 公司/交易所公告、CNINFO、投资者关系材料 | 首次公开时间、是否新增内容、A/H渠道覆盖 |
| 产业实际传导 | 官方统计、行业协会、口径透明的行业数据、企业经营披露 | 出货/终端零售/排产区分，样本与地域、季节性和披露滞后 |
| 政策与执行 | 发布机关原文、实施细则、执行数据 | 成文/公开/生效日期、地域、对象、旧新规则对照 |
| 基金身份/净值/分红 | 管理人产品页、净值与分红公告；结构化接口辅助 | 全称、代码、份额、共同日期、分红折算 |
| 基金结构与风险 | 定期报告、合同、风险/费用附注 | 同期归属、完整程度、冲击大小与分母 |
| 债券身份/现金流 | 发行文件、募集说明书、清算机构、评级原文 | 精确代码、永续/含权条款、实际赎回、票息/重置 |
| 债券市场变化 | 对应期限/评级/券种的历史曲线或授权估值 | 估值/成交、净价/全价、应计利息与期间覆盖 |
| BTC现货/衍生品 | 交易平台公开数据、明确覆盖的数据提供方 | 平台、报价币种、时区、合约范围、单位、缺失 |
| ETF/产品资金 | 发行人份额与申赎披露，可靠汇总用于交叉核对 | 净申赎与市值变化的区别、披露滞后、交易日 |
| 宏观与预期 | 统计机构、央行原文、可追溯预期/市场数据 | 数据版本、发布时间、预测与实际的可比口径 |
| 已有解释与反方 | 专业研究、经理访谈、媒体、投资者讨论 | 作者、发布日期、适用窗口、原始依据；观点不能升格为事实 |

不要把来源选择简化为“只读公告”或“多搜几篇新闻”。公告负责核实事实，产业/市场数据负责核对传导，有论据的专业分析负责发现机制与分歧。缺其中一环时，明确哪些结论因此不能成立。研究者提出的新机制应回到基本面结构检查，不能为了凑多源只收集重复叙事。

使用Tushare、财报读取或OpenCLI等技能时，读取对应技能并检查可用性。上市公司报告下载能力不等于基金报告发现能力；股票持仓接口也不等于完整债券持仓接口。没有某个库可用不妨碍先走公开网页和原始文档。

## 查询与验证

先发现准确实体、公告目录、数据字段，再按时间和候选机制精查。遇返回上限分页或缩窗。检索最有支持的解释时同步搜索反证，不能只找同义报道。

最小检查：
- 结构化返回：身份、单位、时间覆盖、唯一性、缺失值、数值类型；
- 文档：确为目标报告/附件，关键表格有内容、可定位回原页；
- 网页：实际读到正文；搜索摘要、HTTP200、页面框架或验证码不算取得；
- 行情：同窗、时区、最新共同日期及价格/总回报口径；
- 敏感性/模型：输入与实际对象匹配，输出范围没有超过输入支持。

原文表格提取异常时查看原页或截图，不能凭文本搜索无命中说原文没有。

数据端点/签名可能变化，调用前检查已安装版本与官方文档。过去成功记录只能作候选。不要调用不存在的 `icai preflight` 等命令，也不要为本次分析默认安装整套新数据栈。

## 失败与来源独立性

区分未检索、认证/权限、限流、网络、实体/范围错误、截断、解析失败与确实不公开。失败后用公开替代路径，重要失败和替代尝试写入证据台账。同参数连续失败两次换路；权限拒绝不重复碰撞。

数据商包装器共用一个上游、媒体转载同一公告，均不算独立佐证。拿不到个券价格时，适配曲线能检验部分市场机制，但不能冒充实际个券损益。

不输出token等凭证；不绕过付费、认证与隐私边界。保存允许保留的数据或必要摘录和来源，避免保存整篇受限文章。公开材料缺失只限制依赖它的结论，独立证据工作继续推进。
