# 按问题选择归因方法

## 经营与财务变化

先按 [理解基本面](fundamentals.md) 确认主要业务和经济敞口，再拆指标。财务标签不是经济原因：例如扣非下降仍需检查汇兑与套保分类、减值及业务组合，不能直接等同核心经营恶化。定量拆解放研究附件，正文保留足以改变主判断的桥接环节。

- 收入：优先使用披露的销量、售价、业务组合、汇率、并表范围拆解。多因素交互项应单列或说明分配方法；数据不支持时不制造精确贡献率。
- 利润：连接收入、毛利率、费用、减值、投资收益、税率与少数股东损益。统一利润口径，区分持续经营与一次性因素；先处理同期基数。
- 现金流：从利润与经营现金流差异出发，检查应收、存货、应付及非现金项目。资产负债表期末变动可能受到汇率、并购和重分类影响，不能直接当现金流量。
- 分红：区分已实施、已批准、董事会预案、政策表述和研究者预测。盈利、现金、资本开支及监管约束只是分析条件，不能替代实际分配方案。

使用桥接表展示“期初/同期 → 各项贡献 → 期末/本期”；保留无法解释的剩余项。分部数据加总前检查内部抵销与口径变化。

## 股价与估值变化

先比较个股、相关行业和市场同一期间的回报。简单减去基准回报只作描述性超额回报；未经模型检验，不称风险调整后的异常收益。

当 EPS 为正且两个时点口径可比时，P = EPS × PE 可以拆解价格变动：

`ln(P1/P0) = ln(EPS1/EPS0) + ln(PE1/PE0)`

这是恒等式。估值由价格反算，不能用“PE 下跌”独立解释价格下跌的原因。进一步检查增长预期、折现率或风险判断是否有独立证据；历史 EPS 变化也不能代替盈利预期变化。负利润或利润接近零时选择适合业务的其他指标并说明局限。

价格回报与包含分红的总回报分别核算，避免在总回报中重复加分红。检查拆股、除权、停牌、汇率及复权数据，避免把技术调整解释成经济损失。

## 对照与反事实

- 同业同期：事前说明可比性，检查业务、地域、规模、杠杆与估值差异，避免只挑支持结论的公司。
- 事件前后：明确公告时点、事件窗口与同期其他消息；检查提前反应和信息泄漏可能。单事件对照的因果识别通常有限。
- 历史同类事件：说明样本选取和制度、业务环境变化，保留失败或相反样本。
- 情景测算：说明“若其他条件不变”的假设；模型输出是条件估计，不是实际发生的替代历史。

根据数据和问题决定是否使用统计方法；样本量、对照质量或信息时点不支持时，应输出不可识别，而非追加模型制造确定性。
